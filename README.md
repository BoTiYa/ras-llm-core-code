# Core code for the RAS management framework
This repository accompanies the study “An LLM-Enabled Intelligent Management Framework for Industrial Recirculating Aquaculture Systems.” It provides the selected algorithm code prepared for the paper’s public code deposit.
## Contents
- [RAS_core_code_v1.0.zip](./RAS_core_code_v1.0.zip): a packaged snapshot containing the available MC-YOLOv10 configuration and modified detection-framework modules, together with the available QLoRA training prototype and its setup files.
## Scope and reproducibility
This is a focused code deposit, not a complete end-to-end reproduction package. Pretrained model weights are not included. The archive does not include the TCN-Attention implementation or the complete tracking, texture-to-feeding-activity, and perception-to-control integration. The paper describes the model composition and system workflow in its Methods and figures. The QLoRA materials are a prototype/reference implementation and do not include Qwen3-8B weights or the full instruction corpus.
The data deposit is on Figshare: [10.6084/m9.figshare.35048500](https://doi.org/10.6084/m9.figshare.35048500). This DOI is reserved and will become active when the Figshare item is published.
